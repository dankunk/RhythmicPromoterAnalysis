# Promoter Analysis Pipeline for *Rhopalosiphum padi*

This repository contains scripts and analysis workflows used to generate
and analyze promoter regions for *Rhopalosiphum padi* transcripts, with
a focus on identifying regulatory motifs associated with transcriptional
rhythmicity.

## Overview

The goal of this project is to extract upstream promoter sequences from
the *R. padi* genome and perform motif enrichment analyses on subsets of
transcripts (e.g., rhythmic vs. arrhythmic genes). This workflow
supports downstream analyses such as MEME Suite (FIMO, XSTREME) motif
discovery and enrichment testing.

The repository includes scripts for: - Building transcript databases
from genome annotations - Extracting transcript IDs from gene-level
identifiers - Generating upstream promoter sequences - Running motif
scanning and enrichment analyses - Organizing outputs for downstream
interpretation and visualization

## Repository Structure

-   `create_TxDb.R`\
    Builds a TxDb object from genome annotation files for
    coordinate-based operations.

-   `Grab_txIDs_from_GeneID.Rmd`\
    Extracts transcript IDs corresponding to gene IDs of interest.

-   `extract_upstream_features.R`\
    Core script for extracting upstream promoter regions from genomic
    coordinates.

-   `extract_upstream_features_rhythmic.R`\
    Variant of upstream extraction tailored for rhythmic gene sets.

-   `ExtractUpstreamFeatures.Rmd`\
    Documentation and workflow for promoter extraction steps.

-   `fimo_analysis.Rmd`\
    Analysis pipeline for motif scanning results generated by FIMO.

-   `model_promoter_fastas/`\
    Directory containing generated FASTA files of promoter sequences
    used for motif analysis.

-   `promoter_analysis.Rproj`\
    RStudio project file for reproducibility and environment management.

-   `.gitignore`\
    Configured to exclude large genome files, intermediate outputs, and
    analysis artifacts (e.g., XSTREME results).

## Notes on Data

Large genome files, intermediate outputs, and motif analysis results
(e.g., XSTREME output directories) are excluded from version control to
maintain a lightweight and reproducible repository. These files can be
regenerated using the provided scripts or accessed via associated data
repositories (e.g., Figshare).

## Requirements

-   R (≥ 4.0)
-   Bioconductor packages (e.g., `GenomicFeatures`, `GenomicRanges`)
-   MEME Suite tools (for motif analysis; run externally)

## Usage

Typical workflow: 1. Build TxDb from genome annotation (`create_TxDb.R`)
2. Extract transcript IDs of interest 3. Generate promoter FASTA
sequences 4. Run motif discovery/enrichment externally (e.g., XSTREME,
FIMO) 5. Analyze results using provided RMarkdown scripts

## Reproducibility

This repository is designed to integrate with larger RNA-seq and
rhythmicity analysis pipelines. File paths and inputs may need to be
adapted depending on local or HPC environments.
